# Florza - E-commerce Website for Indoor Plants

## Description
Florza is an e-commerce web application developed using ASP.NET and SQL Server. It allows users to buy indoor plants through an interactive and user-friendly interface.

## Features
- User registration and login
- Product listing and management
- Order management system
- Admin and User modules

## Technologies Used
- ASP.NET
- C#
- SQL Server
- HTML, CSS, JavaScript
